# desktop_mascot 仕様書 v0.1

## 前提

- 自分用・趣味プロジェクト（Windows）
- 見た目: 2D画像 / アニメーション
- キャラクター: スライム（詳細は未定）

## 技術スタック

- Electron + TypeScript
- 透明・最前面・クリック透過ウィンドウでマスコットを表示
- 描画は HTML/CSS（スプライト切替・CSSアニメーション）

## 機能

### 1. 表示・癒し

- 透明ウィンドウでキャラクターを表示（常に最前面）
- ドラッグで移動、位置を記憶
- 状態ごとの画像切替: 待機 / 歩く / クリックされた / ポーズ / 揺れ / 寝る
- 待機中にランダムで行動する（画面下端を跳ねながら左右に歩く・ポーズ・揺れ）
- 吹き出しでひとことしゃべる
- タスクトレイアイコン: 表示/非表示・設定・終了
- PC 起動時の自動実行（トレイで切替）

### 2. 便利機能

- 時計（時報）、アラーム、ポモドーロタイマー
- 通知はマスコットの吹き出しと通知音で知らせる（音はトレイでオン/オフ）

### 3. PC状態通知

- CPU・メモリ・バッテリーを定期監視
- しきい値を超えたら吹き出しで知らせる

### 4. AI会話

- マスコットをダブルクリック → 入力欄 → AIが吹き出しで返答
- Claude API を使用、キャラ設定（口調など）はシステムプロンプトで指定
- APIキーは設定ファイルに保存し、Git には含めない
- 会話履歴は直近数ターンのみ保持

## 開発フェーズ

1. **Phase 1**: 表示・ドラッグ・トレイ・状態切替（仮画像）
2. **Phase 2**: 歩き回り・吹き出し・時計/タイマー
3. **Phase 3**: PC状態通知
4. **Phase 4**: AI会話
