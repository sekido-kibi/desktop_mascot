# desktop_mascot 詳細仕様書 v0.2

全体方針・フェーズ計画は [SPEC.md](SPEC.md) を参照。本書は実装済み機能（Phase 1・2）の具体的な動作を定める。

## 1. 構成

| パス | 役割 |
|---|---|
| `src/main.ts` | メインプロセス。ウィンドウ・トレイ・タイマー類・位置保存 |
| `src/preload.ts` | renderer に `window.mascot` API を公開（contextBridge） |
| `src/renderer.ts` | 描画・アニメーション・ドラッグ・待機中の行動（歩く・ポーズ・揺れ）・吹き出し |
| `renderer/index.html`, `style.css` | 画面（吹き出し＋スプライト） |
| `imgs/mouse_slime_1〜6.png` | スプライト画像 |
| `dist/` | ビルド出力（Git 管理外） |

- 起動: `npm start`（`tsc` → `electron .`）
- 多重起動禁止（2つ目は即終了）

## 2. ウィンドウ

| 項目 | 値 |
|---|---|
| サイズ | 200 × 180 px（上部が吹き出し領域、下部 100 × 100 がキャラ） |
| 属性 | 透明・枠なし・リサイズ不可・タスクバー非表示・影なし |
| 最前面 | `screen-saver` レベルで常に最前面 |
| 初期位置 | プライマリディスプレイ作業領域の右下（右端から 40px 内側、下端に接地） |
| クリック透過 | キャラ・吹き出し以外の透明部分はクリックが背面へ抜ける |

## 3. キャラクター状態

| 状態 | 画像（番号） | 切替間隔 | ループ | 遷移 |
|---|---|---|---|---|
| 待機 idle | 1 | — | する | 初期状態 |
| クリック click | 5, 3, 1 | 120ms | しない | 終了後 idle へ |
| 歩く walk | 1, 1, 1, 1, 1 | 120ms | する | 歩行終了で idle へ（1 周 = 1 ホップ） |
| ポーズ pose | 2 | 3000ms | しない | 3 秒後 idle へ |
| 揺れ sway | 4 | 5000ms | しない | 足元を軸に ±10° を 1 秒周期で揺れ、5 秒後 idle へ |
| 寝る sleep | 6 | — | する | 最後の操作から 60 秒で遷移 |

- 寝ている間にクリック・ドラッグ・吹き出し通知があると起きる

## 4. 操作

### ドラッグ
- 左ボタンで 3px 以上動かすとドラッグ、未満で離すとクリック扱い
- 歩行・ポーズ・揺れの最中にドラッグすると中止
- 離した位置が作業領域の下端から 40px 以内なら下端に吸着（接地）
- 離した時点で位置を保存

### クリック
- click アニメーションを再生し（行動中なら中断して）、以下からランダムに吹き出しでしゃべる
  「ぷるん」「なあに？」「つつかないで〜」「えへへ」「ぽよん！」

## 5. 待機中の行動

- 4 秒ごとに判定し、idle かつ非ドラッグ中なら 30% の確率で行動する（寝ている間は行動しない）
- 行動は「歩く・ポーズ・揺れ」から等確率（各 1/3）で選ぶ
- ポーズ・揺れの内容は「3. キャラクター状態」を参照
- 行動は睡眠タイマーをリセットしない（放置すれば寝る）

### 歩く

- 小さく跳ねながら進む（1 ホップ 600ms、高さ 20px）。横移動は空中の間だけ、50ms ごとに 3px
- 方向は左右ランダム、3〜9 ホップ（約 2〜5 秒）。ホップの途中では止まらない
- 上下の跳ねはウィンドウ内でスプライトのみを動かす（ウィンドウ位置は不変）
- 横移動は接地しているとき（下端との差 2px 以内）のみ。画面端に達するか接地していなければ、そのホップで停止する
  （そのため画面端や空中に置いた状態では、その場で 1 回跳ねて終わる）
- 歩行終了時に位置を保存

## 6. 吹き出し

- キャラの真上に表示（最大幅 180px、しっぽ付き）
- 表示時間: 既定 4 秒。時報 8 秒、タイマー・ポモドーロ完了 15 秒
- クリックで即消去
- 非表示中に通知が来た場合はウィンドウを（フォーカスを奪わずに）表示する

## 7. トレイ

アイコンは `mouse_slime_1.png` を 16px に縮小。左クリックで表示/非表示切替。

右クリックメニュー:

| 項目 | 動作 |
|---|---|
| 表示 / 非表示 | ウィンドウの表示切替 |
| タイマー ▸ 3/5/10/30/60分・停止 | 開始時「N分はかるね」、完了時「N分たったよ！」。計測中は項目名に表示。新たに開始すると前のタイマーは破棄 |
| ポモドーロ開始 / 停止 | 25 分作業 → 5 分休憩を停止まで繰り返す。各区切りで吹き出し通知。項目名に作業中/休憩中を表示 |
| 時報（チェック） | 毎時 0 分に「H時だよ！」。既定オン、設定は保存される |
| 終了 | アプリ終了（位置を保存） |

## 8. 保存データ

`%APPDATA%/desktop_mascot/state.json`（Electron の userData）

```json
{ "x": 1700, "y": 860, "chime": true }
```

- 保存位置がどのディスプレイの作業領域にも収まらない場合は初期位置を使う
- 読み込み失敗時はすべて既定値

## 9. プロセス間通信（IPC）

| チャネル | 方向 | 内容 |
|---|---|---|
| `set-ignore-mouse(ignore)` | R → M | クリック透過の切替 |
| `drag-move(dx, dy)` | R → M | ウィンドウを相対移動 |
| `drag-end` | R → M | 接地判定と位置保存 |
| `walk-step(dx)` → boolean | R → M（invoke） | 接地中なら横移動。移動できなければ false |
| `walk-end` | R → M | 位置保存 |
| `say(text, ms?)` | M → R | 吹き出し表示 |
